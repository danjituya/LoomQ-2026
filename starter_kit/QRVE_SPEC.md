# QRVE v1.0 · 量子 RISC-V 扩展指令编码规格 (Quantum RISC-V Extension)

> 本文件是 LoomQ 申报 **Bonus「自定义量子 RISC-V 扩展指令」+8 分** 的第①项：
> **指令编码规格文档**。对应的 ② 模拟器扩展实现位于 `quantum_riscv_ext.py::QuantumRISCVSimulator`；
> ③ 端到端测试由 `python quantum_riscv_ext.py` 直接运行输出并由 `test_qrve_bonus.py` 覆盖。

---

## 1. 设计动机

官方 L3 已经支持了 Hybrid-QASM，即经典控制块（`if/else`, 算术）与量子门并行存在，但经典
部分只能"读测量结果、计算、写寄存器"，**不能在 RISC-V 汇编层面直接操纵量子比特**。

为了把"经典-量子混合"真正做到指令集层面，我们在基础 TinyRISCVEmulator 上扩展一套
**量子 RISC-V 伪指令集 (QRVE)**，使经典控制程序可以：

```text
# RISC-V 汇编里直接写量子电路
li  x1, 0         # x1 = 目标比特索引 q[0]
Q.H x0, x1        # 在 q[0] 上施加 H 门
Q.MEAS x10, x1    # 测量 q[0]，结果写回经典寄存器 x10（即 c[0]）
```

这样经典程序不只是"读取测量结果并分支"，而是**以经典程序驱动量子态演化**，实现真正的
经典-量子同构编程模型。

## 2. 指令集总览

QRVE 指令以 `Q.` 前缀标识，全部是"伪指令助记符"形式；选手/评测代码不需要写二进制编码，
汇编器接受文本助记符即可。

| 类别 | 助记符 | 操作数 | 语义（12 门白名单全覆盖）|
|---|---|---|---|
| 无参单比特 | `Q.H` | `rd, rs1` | H 门，施加到 rs1 指向的量子比特 |
| 无参单比特 | `Q.X` | `rd, rs1` | Pauli-X (NOT) 门 |
| 无参单比特 | `Q.S` | `rd, rs1` | S 门 (π/2 相位) |
| 无参单比特 | `Q.SDG` | `rd, rs1` | S† 门 |
| 无参单比特 | `Q.T` | `rd, rs1` | T 门 (π/4 相位) |
| 无参单比特 | `Q.TDG` | `rd, rs1` | T† 门 |
| 参数单比特 | `Q.RZ` | `rd, rs1, rs2` | Rz(θ)：rs1=目标比特，rs2=角度表索引 |
| 参数单比特 | `Q.RY` | `rd, rs1, rs2` | Ry(θ)：同上 |
| 两比特 | `Q.CX` | `rd, rs1, rs2` | CNOT：rs1=控制，rs2=目标 |
| 两比特 | `Q.SWAP` | `rd, rs1, rs2` | SWAP：rs1, rs2 两比特交换 |
| 受控参数 | `Q.CU1` | `rd, rs1, rs2, rs3` | CU1(θ)：rs1=控制, rs2=目标, rs3=角度表索引 |
| 三比特 | `Q.CCX` | `rd, rs1, rs2, rs3` | Toffoli：rs1,rs2=控制, rs3=目标 |
| 辅助 | `Q.SETF` | `rs1, imm` | 载入浮点角度值到角度表：rs1=索引(0..7), imm=十进制浮点数或 IEEE-754 float32 编码的整数 |
| 测量 | `Q.MEAS` | `rd, rs1` | 测量 rs1 指向的量子比特，结果 (0/1) 写入 rd 通用寄存器 |
| 辅助(调试) | `Q.RESET` | 无 | 重置整个量子寄存器到 \|0…0⟩，清零门计数 |

> `rd` 字段在大多数量子指令中为「保留字段，建议写 x0」，这样编码格式统一为 R-type；
> 文本汇编层允许省略 `rd` 只写两个操作数，汇编器自动在内部补 x0。

## 3. 角度表与 Q.SETF 细节

参数门 (RZ/RY/CU1) 的角度值**不直接编码在指令立立即数中**（RISC-V I-type 只有 12 位
立即数，装不下 float32），而是通过一个 8 项的"角度表"间接寻址：

```text
角度表: angle_table[0..7]  (float32, 初始全 0)

# 例：把 π/2 载入 angle_table[0]，然后在 q[0] 上施加 Ry(π/2)
li    x5, 0            # 索引 = 0
Q.SETF x5, 1.570796327 # angle_table[0] ← 1.570796327 (≈ π/2)
li    x1, 0            # 目标比特 = q[0]
Q.RY  x0, x1, x5       # Rz(angle_table[x5]) 施加到 q[x1]
```

`Q.SETF` 的 imm 字段同时接受两种形式：
1. **十进制浮点字面量**：`Q.SETF x5, 3.141592654`（汇编器自动编码为 float32）
2. **IEEE-754 单精度整数编码**：`Q.SETF x5, 0x40490FDA`（适用于需要精确控制比特的场景）

## 4. 操作数取值范围与行为约定

| 资源 | 范围 | 越界行为 |
|---|---|---|
| 通用寄存器 rd/rs1/rs2/rs3 | `x0`..`x31` | `ValueError` 立即失败 |
| 量子比特索引（rs1..rs3 指向的值） | `0..N_QUBITS_MAX-1`（默认 N=12） | `ValueError` |
| 角度表索引 | `0..7` | 越界时降级为"把索引值本身当角度（弧度 float）"，便于调试 |
| 经典测量结果（`Q.MEAS rd, _`） | 写入 rd 的是 0 或 1（按概率坍缩） | 其余通用寄存器不受影响 |
| 最大量子比特数 | 12（与 Oracle 模拟器上界一致） | 构造时可缩减，但不能超过 12 |

## 5. 与官方 L3 寄存器约定的兼容性

为了让同一套汇编也能跑在官方 `TinyRISCVEmulator` 上（把所有 `Q.*` 指令视为注释或空操作，
只验证经典控制流），QRVE 遵守官方 L3 的寄存器映射：

| 寄存器 | 用途 | 说明 |
|---|---|---|
| `x0` | zero | 硬编码为 0 |
| `x1`..`x9` | `r1`..`r9` | 用户经典寄存器（Hybrid-QASM 经典块） |
| `x10`..`x{10+k}` | `c[0]`..`c[k]` | 测量位注入（评测系统在执行前写入） |
| `x28`..`x31` | 保留 | QRVE 内部可用；经典程序建议不使用 |

这个 1:1 的映射保证：L3 评测中不含 `Q.*` 指令的汇编在 QRVE 上行为与官方模拟器逐比特
等价（我们的 E2E Test 2 覆盖了这一断言）。

## 6. 二进制编码规格（提交完整性的说明；评测以文本助记符为准）

尽管提交按"文本伪指令"运行，这里仍给出正式的 R-type / I-type 编码方案供评审验证
（映射到 RISC-V custom-0 空间 opcode = 0b0001011）：

```text
6 种量子指令类型 → funct7 (7 bit)
--------------------------------------
0000001 = Q.H        # R: rd(rs2=0) rs1 = q_idx
0000010 = Q.X
0000011 = Q.S
0000100 = Q.SDG
0000101 = Q.T
0000110 = Q.TDG
0001001 = Q.RZ       # R: rs1=q_idx, rs2=angle_idx
0001010 = Q.RY       # R: 同上
0010001 = Q.CX       # R: rs1=ctrl, rs2=tgt
0010010 = Q.SWAP     # R: rs1=a, rs2=b
0010011 = Q.CU1      # R: rs1=ctrl, rs2=tgt (angle 在 rs3 → funct3 编码索引 0..7)
0010100 = Q.CCX      # R: rs1=cA, rs2=cB (tgt 在 rs3 → funct3 编码)
0100000 = Q.SETF     # I-type: rs1 = index, imm12 = (float32 编码的低 12 位 + 高位通过 Q.SETHI 扩展——
                     #           文本层省略该复杂性，允许直接写浮点字面量)
1000000 = Q.MEAS     # R: rd = 输出经典寄存器, rs1 = 量子比特索引
```

对于"选手面向的文本汇编接口"，上面的 funct7 编码仅作为证明 QRVE 是一个可硬件化的指令集，
而不是字符串魔法。

## 7. 端到端覆盖的 4 类代表性用例（证明规格不空洞）

详见 `quantum_riscv_ext.py::run_e2e_tests()`，每类断言：
1. **Test 1 · Bell 态制备**：Q.H + Q.CX → 结果落在 {00,11} 子空间（概率幅之和 > 0.99）
2. **Test 2 · 经典反馈条件控制**：`beq x10, x0, SKIP` + Q.X → GHZ 子空间仍保真（证明经典/量子
   指令可以任意交织）
3. **Test 3 · 参数门**：Q.SETF 载入 π/2 → Q.RY 等价 H，再 Q.CX 制备 Bell 态（证明角度表
   与参数门流水线正确）
4. **Test 4 · SWAP + Toffoli 制造 \|101⟩**：验证两比特/三比特门的完整路径

四项全部通过才构成 Bonus 有效交付。
